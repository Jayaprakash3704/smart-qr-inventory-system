# smart-qr-inventory-system

Smart QR Inventory Management System containing both Mobile (Flutter) and Desktop (Python/ERP) applications for Yarn Tracking and Inventory Management.

## Projects

- **Yarn-Manager-Mobile-App**: Flutter Mobile Application for scanning QR codes and managing yarn inventory dispatch, reservation, and details.
- **Yarn-Tracker-Desktop-App**: Desktop Application for Yarn Tracking & ERP Management.
